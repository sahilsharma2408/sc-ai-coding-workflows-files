Inference at the Edge of Your IDE

08

Five commands. node setup.mjs --check confirms everything is ready. Go to bench/task-board. Open lab/workshop/mission.md and read the mission aloud. Then run a setup, for example node lab/workshop/bench.mjs run 3. When it finishes, node lab/workshop/bench.mjs report --open builds the report. To run several at once: node lab/workshop/bench.mjs run-all --only 1,2,3,4 --parallel. Claude Code needs a paid plan or API billing, so setups 1 and 2 are optional for attendees.
