06

Before the next part, get your environment ready. Clone the repo, run node setup.mjs, and read what it reports. It installs the DeepSeek harness and the scoring tools, checks your OpenRouter key, and finds any local model server. You need Node 22.22 or newer and an OpenRouter key exported as OPENROUTER_API_KEY. If the key is missing, the script asks for one and never saves it.
