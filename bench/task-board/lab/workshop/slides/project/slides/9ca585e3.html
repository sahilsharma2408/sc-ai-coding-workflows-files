Inference at the Edge of Your IDE

04

In this workshop you compare AI coding setups on one mission. Every setup is three choices stacked together: the coding agent, where the model runs, and which model. We change those choices and keep the job the same, so the comparison stays fair. The job is a small React task board, and the mission is to add labels to it across about twenty files. Hidden tests score the result, and we record cost, time and tokens for every run.
