Setup 5 is the hybrid. The planning stays in the cloud on V4 Flash, and a small local model, Gemma 4, does the implementation. Before you run it, start your local model server with a large context, for example OLLAMA_CONTEXT_LENGTH=65536 ollama serve, and run node setup.mjs --check to see the model names. Then run node lab/workshop/bench.mjs run 5. Watch the rule check: if the orchestrator edits files itself, the hybrid did not really happen. In our own test, Flash did edit files itself, and the report flagged it.
