Inference at the Edge of Your IDE

07

One mission, seven setups. The mission file says what to build, what done means and how the work is judged. Every setup gets exactly the same text as MISSION.md in a fresh folder. Hidden tests that the model never sees score the work out of 100: 60 for the mission itself, 25 for behaviour that already worked, and 15 for hygiene such as type-checking and building. Each part is curved, so almost right earns much less than right. Every run saves its score, cost, time, tokens and rule check, and one report puts all setups side by side. The four groups on the right are the setups: Claude Code with Sonnet and Haiku, the DeepSeek harness with cloud models, the hybrid, and fully local.
