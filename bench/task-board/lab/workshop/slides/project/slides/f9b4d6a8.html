Inference at the Edge of Your IDE

The agent still needs a model to talk to. Now that you have moved away from Claude Code you are no longer restricted to Anthropic models. The harness can connect to many different models, but setting each one up separately means juggling accounts, keys and billing. That is where OpenRouter comes in: one API connection to a catalog of models, so you choose the model while OpenRouter handles the rest. OpenRouter charges based on token usage, so you add a small amount of credit. First go to the OpenRouter site and create a login. You then have a two-step process: add some credit to your account, about $10 should be plenty, and create an API key. This is how the harness connects to OpenRouter. Copy the key right away, because you cannot come back later and get it, and API keys are secrets: do not share them with anyone, and keep them out of Git. In the harness, add OpenRouter as a custom provider. Then choose your models. DeepSeek V4 Pro in particular is a good fit for what we are doing; check current prices on OpenRouter, since they change. You start with Pro and use Flash later for subagents. To avoid a long, cumbersome model list, include only those two models, and set reasoning to medium if the harness offers it. Confirm it works: start a new chat, check the model picker shows only your two models, and send a hello prompt. You are now ready to return to development. On the slide before the redesign: Create an OpenRouter account. Add credits. About $10 is plenty for the workshop. Create an API key and copy it right away. You can’t view it again, and it is a secret. In the harness, open Settings, then Models, then Add custom provider. Use the base URL https://openrouter.ai/api/v1 and paste your key. List only DeepSeek V4 Pro and DeepSeek V4 Flash, set reasoning to medium if offered, and send a hello prompt to confirm. What OpenRouter gives you One account and one API key for a catalog of models, hosted by many inference providers. You pay by token usage, and you choose the model. The models still run in the cloud, but you now control which one your coding agent uses. Keep the key out of Git. Check current model prices on OpenRouter before you choose.
