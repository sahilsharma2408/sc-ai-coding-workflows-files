Inference at the Edge of Your IDE

09

Setup 1 is the baseline: Claude Code with Sonnet working alone on the mission. Run it with node lab/workshop/bench.mjs run 1. The agent can read, search and edit files, but it cannot run anything, and it gets one pass. When it finishes, the tool scores it with hidden tests and records the cost, time and tokens. Read the score, the cost and the rule check. We chose Sonnet for a good balance of cost and power. Later setups change one thing at a time.
