Seven setups, one mission

The launch command and prompt for each setup in the live demo. Every setup works on the labels feature in its own folder, and when the mission is done it starts the app and scores itself with the benchmark scorer.

Before you start

  1. Make the seven mission folders. They sit outside the repo, so the agents cannot see the hidden tests or the reference solution. Skip this if ~/task-board-live already exists.
    Run once, from the repo root
    cd ~/workspace/sc-ai-coding-workflows-files
for s in s1 s2 s3 s4 s5 s6 s7; do node bench/task-board/lab/workshop/ladder.mjs start labels-feature --model live-$s --root ~/task-board-live; done
  2. In every terminal you open, set the overlay folder and the OpenRouter key.
    Each terminal
    L=~/workspace/sc-ai-coding-workflows-files/bench/task-board/lab/workshop/live
export OPENROUTER_API_KEY=sk-or-...
  3. Open one terminal per setup, cd into that setup's folder, run its command, then paste its prompt.

During the demo

  • Each app gets its own address. Vite takes 5173 first, then 5174 and so on. Stop all of them with pkill -f vite.
  • The agent asks before it runs npm install and the dev server. Approve both. In Claude Code you can skip the question by adding --allowedTools "Bash(npm *),Bash(nohup *)".
  • Setups 5, 6 and 7 share Ollama on this laptop. Run them one at a time, and not while the benchmark is running.
  • Setup 7 took 12 to 21 minutes on the easier tasks in the benchmark. Start it early or show the stored result instead.
  • Each live run scores itself at the end. To compare the live runs side by side, models down and score, cost and time across, run node ~/workspace/sc-ai-coding-workflows-files/bench/task-board/lab/workshop/ladder.mjs table --root ~/task-board-live.
  • Live cost is approximate: Claude Code runs show no cost, and DeepSeek runs share one key, so overlapping runs blur each other's figure. The exact costs are in the benchmark report.
