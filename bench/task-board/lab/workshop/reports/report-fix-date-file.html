How to read this

  • Score is out of 100 from hidden tests: the mission itself 60, existing behaviour 25, hygiene 15 (type-check, build, scope, tests kept). Each part is curved, so almost right earns much less than right.
  • Cost for the DeepSeek harness is what OpenRouter charged for each reply. For Claude Code it is Claude Code's own figure at list prices. Local models cost $0 in money, not in time, memory or power.
  • One run is a sample, not a ranking. The same model can score very differently on the same job from one run to the next.
  • Time is only fair for runs done one at a time. When setups run together they share one laptop, and a local model can slow down while cloud runs and scoring are busy.
  • Rules: a setup meant to use sub-agents should use them, an orchestrator should not edit files itself, a setup that works alone should not start sub-agents, and nobody runs shell commands.
  • Turns are model replies. Tool calls are the reads, searches and edits that followed. Tokens are input, output and cached input together.
